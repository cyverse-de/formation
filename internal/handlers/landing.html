MCP Server

Formation hosts a Model Context Protocol server over streamable HTTP:

{{.MCPURL}}

Authentication uses OAuth via CyVerse Keycloak with standard MCP discovery and dynamic client registration — clients that support MCP OAuth only need the URL above and will open a browser so you can log in with your CyVerse account.

Claude Code

claude mcp add --transport http formation {{.MCPURL}}

Cursor, VS Code, and other clients

For clients that accept remote servers in an mcpServers config block:

{
  "mcpServers": {
    "formation": {
      "type": "http",
      "url": "{{.MCPURL}}"
    }
  }
}

In Claude Desktop or claude.ai, use Settings → Connectors → Add custom connector with the URL above instead — the desktop config file only supports local stdio servers.

Google Antigravity 2.0 and the agy CLI

Both share ~/.gemini/config/mcp_config.json; note that Antigravity uses serverUrl rather than url:

{
  "mcpServers": {
    "formation": {
      "serverUrl": "{{.MCPURL}}"
    }
  }
}

Then refresh the Installed MCP Servers panel in the GUI, or run /mcp in agy.
